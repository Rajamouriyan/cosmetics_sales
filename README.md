# 💄 Cosmetics Sales Performance Dashboard (2022)

## 📊 Project Overview
This project analyzes 2022 cosmetics sales data to identify key performance trends, top-selling products, and high-performing regions.  
It integrates **Excel**, **SQL**, **Python**, and **Power BI** for end-to-end data analysis and visualization.

---

## 🧠 Objectives
- Clean and prepare sales data using Excel and Python.
- Query and aggregate data using SQL.
- Visualize insights with interactive Power BI dashboards.
- Derive actionable business insights for decision-making.

---

## 🧰 Tools & Technologies
- **Excel** – Initial data cleaning and pivot analysis  
- **SQL (SQLite)** – Data querying and aggregation  
- **Python (Pandas, Seaborn, Matplotlib)** – EDA and visualization  
- **Power BI** – Interactive dashboard creation  

---

## 🧾 Data Fields
| Column | Description |
|--------|--------------|
| Date | Date of transaction |
| Country | Customer country |
| Product | Product name |
| Sales_Person | Responsible salesperson |
| Amount | Total sale value |
| Boxes_Shipped | Number of boxes shipped |

---

## 📈 Key Visuals in Power BI
- **KPI Cards**: Total Sales, Total Orders
- **Sales by Country** (bar chart)  
- **Monthly Sales Trend** (line chart)  
- **Top Products by Sales** (treemap)  
- **Sales by Salesperson** (column chart)  
- **Interactive slicers** for Country, Product, Month  

---

## 💡 Business Insights
1. **USA and UK** generated over 60% of total global sales.  
2. **Lipstick** and **Serum** were top-performing categories.  
3. **Sales peaked in November–December**, suggesting seasonal demand.  
4. **Emma Brown** led individual sales performance with $220K revenue.  
5. **Australia and New Zealand** show potential for marketing expansion.  

---

## 🚀 How to Use
1. Clone this repository.  
2. Open `analysis/cosmetics_sales_analysis.ipynb` for Python exploration.  
3. Open `dashboard/Cosmetics_Sales_Dashboard.pbix` in Power BI Desktop.  
4. Use slicers (Country, Month, Product) to interact with visuals.
